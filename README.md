# 砚笺 YanJian · 思源笔记主题

> **同一间书房的两种时辰——浅色是日光下的宣纸，深色是夜灯旁的砚台。**
> 用文房器物的克制配色与中文优先的排版，让界面退成纸，让块与双链成为墨迹。

- **笺（浅色）**：米黄宣纸底（`#FAF7F1`）配青花靛青交互（`#2F5D8A`），朱砂点缀（`#B3362A`）
- **砚（深色）**：暖墨砚台底（`#26241F`）配灯下亮青（`#82A7CC`），灯照朱砂提示（`#E07B6D`）

两套色调独立设计与校对，深色不走机械反相，夜间读写温润不刺眼。

---

## 快速上手

### 方式 A：集市安装（推荐）

主题上架思源集市后：
1. 打开思源笔记 → `设置` → `集市` → `主题`。
2. 搜索 **「砚笺」** 或 **「YanJian」**，点击安装。
3. 进入 `设置` → `外观` → 主题，在浅色与深色模式下分别选择 **「砚笺 YanJian」**。

### 方式 B：手动安装

1. 打开思源笔记 → `设置` → `外观` → 主题区块，点击 **「打开主题文件夹」**（对应工作空间目录：`{工作空间}/conf/appearance/themes/`）。
2. 在该目录下新建文件夹 **`YanJian`**（文件夹名称需与主题名称完全一致）。
3. 将主题包中的 `theme.json`、`theme.css`、`theme-dark.css`、`README.md` 放入该文件夹。
4. 返回思源笔记 → `设置` → `外观`，刷新主题列表，在浅色与深色模式下均选择 **「砚笺 YanJian」**。

## 视觉与排版特色

- **纸墨底色**：浅色采用带暖调的宣纸米黄，深色采用暖墨棕灰，避开刺眼的冷白与冷蓝黑，适合长时间沉浸书写。
- **中文优先排版**：正文默认 1.75 行高，编辑区宽度适中（约 40-45 个中文字），中英文混排自然过渡；在支持的系统上无缝匹配苹方、鸿蒙、微软雅黑或系统黑体，同时也支持用户在思源中自选全局字体。
- **清晰的操作反馈**：可点击的链接、按钮与键盘焦点统一呈靛青色；双链块引用配有黛紫色与左缘墨线；警示与错误使用朱砂红；正在编辑的块与选中块层级清晰分明。
- **全平台自适应**：无论是桌面宽屏、分屏还是移动端手机外壳，版心与边距均能平滑自适应，触屏设备上按钮热区舒适好按。
- **纯粹无冗余**：纯 CSS 实现，无后台常驻脚本，不发起任何外部网络请求，不私自修改工作空间数据。

## 进阶：个性化定制

如果你喜欢个性化微调，可以在思源笔记的 `设置` → `外观` → `代码片段` 中添加自定义 CSS：

```css
/* 示例 1：换一个你喜欢的主色（如松石青，交互色将自动适配推导） */
:root {
  --b3-theme-primary: #345F73;
  --b3-theme-primary-light: rgba(52, 95, 115, .54);
  --b3-theme-primary-lighter: rgba(52, 95, 115, .38);
  --b3-theme-primary-lightest: rgba(52, 95, 115, .12);
}

/* 示例 2：开启书卷衬线字体（仅正文生效，软件界面仍保持黑体） */
.protyle-wysiwyg {
  --b3-font-family-protyle: "Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", SimSun, serif;
}

/* 示例 3：放宽单行字数（默认约 46 字宽，可调宽为 56） */
:root {
  --yj-measure: calc(var(--b3-font-size-editor, 16px) * 56);
}
```

## 卸载

在 `设置` → `外观` 中切换回官方内置的 `daylight` 或 `midnight` 主题，随后直接删除主题目录 `{工作空间}/conf/appearance/themes/YanJian/` 即可，无任何残留文件。
